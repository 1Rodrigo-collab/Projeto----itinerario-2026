#🌟 Jornada das Estrelas

Projeto acadêmico desenvolvido com foco em inclusão, aprendizado lúdico e acessibilidade para crianças com TEA (Transtorno do Espectro Autista), utilizando gamificação para estimular habilidades cognitivas de forma divertida e interativa.

🎮 Sobre o Projeto

Jornada das Estrelas é um jogo educativo web criado para auxiliar crianças no desenvolvimento de:

Reconhecimento de cores
Identificação de formas
Sequências lógicas
Memória
Reconhecimento de emoções

O projeto foi pensado com uma interface amigável, visual acolhedor, sons suaves e modo calmo, proporcionando uma experiência confortável e acessível.

✨ Funcionalidades
🌈 Sistema de fases interativas
🎨 Atividades educativas
🔊 Narração por voz utilizando SpeechSynthesis API
🎵 Sons de feedback positivos
🌙 Modo Calmo para reduzir estímulos visuais
⭐ Sistema de pontuação
🧠 Mini game da memória
😊 Reconhecimento de emoções
📱 Interface responsiva
💙 Tela de créditos personalizada
🕹️ Fases do Jogo
🎨 Fase 1 — Mundo das Cores

A criança deve identificar cores iguais.

🔷 Fase 2 — Terra das Formas

Reconhecimento de formas geométricas.

🌊 Fase 3 — Rio das Sequências

Completar padrões lógicos e sequências.

🧠 Fase 4 — Caverna da Memória

Encontrar pares iguais em um jogo da memória.

😊 Fase 5 — Jardim das Emoções

Reconhecimento de emoções através de expressões faciais.

🎯 Objetivo

Promover inclusão digital e aprendizado interativo através da gamificação, oferecendo uma ferramenta educativa acessível para crianças neurodivergentes.
